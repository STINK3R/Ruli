# Рули — каршеринг в Минске

## Деплой для тестов

На сервере из папки проекта запусти:

```bash
docker compose up -d --build
```

База, миграции, автопарк, тарифы и демо-аккаунты подготовятся автоматически. Для теста с телефона
запусти во втором терминале HTTPS-туннель (нужен установленный `cloudflared`):

```bash
cloudflared tunnel --url http://localhost
```

Открой на телефоне HTTPS-адрес `trycloudflare.com`, который покажет команда. Он нужен для камеры
и установки PWA. Внешний порт публикует только Nginx; приложение и админка доступны по этому адресу.
Этот стенд предназначен для демо: не загружай настоящие документы и персональные данные.

Курсовой проект: веб-приложение поминутной аренды автомобилей. Клиент видит машины
на карте Минска, список отсортирован по времени пешком, к выбранной машине рисуется
пеший маршрут со временем. Бронь, осмотр с фото, поездка и чек — в одном окне.
Права водителя проверяет модератор в системе «Рули ID».

## Быстрый старт

Нужен Docker с Docker Compose (на Windows подойдёт Docker Desktop).

```bash
docker compose up -d --build
```

Первая сборка занимает несколько минут. После неё:

| Что | Адрес |
|---|---|
| Приложение | http://localhost/ |
| Админ-панель (модератор) | http://localhost/admin/ |
| REST API | http://localhost/api/ |

Снаружи опубликован только порт Nginx (по умолчанию `80`). Порты Django и MySQL доступны
только другим контейнерам. Если порт 80 занят, создай рядом с Compose файл `.env` со строкой
`HTTP_PORT=8088`; тогда открой `http://localhost:8088/`, а для телефона запусти
`cloudflared tunnel --url http://localhost:8088`.

Ключ Django создаётся случайным при первом запуске и хранится в отдельном Docker-томе.
При повторном запуске данные и ключ сохраняются; `docker compose down -v` удалит базу,
загруженные фото и ключ.

Учётные записи создаются автоматически (на странице входа есть кнопки быстрого заполнения):

| Логин | Пароль | Кто это |
|---|---|---|
| `admin` | `admin12345` | модератор и администратор |
| `demo` | `demo12345` | «Допуск Плюс»: права подтверждены, 5+ чистых поездок, открыты все классы |
| `novice` | `novice12345` | стаж меньше 2 лет: бизнес и премиум закрыты, видно дату открытия |
| `newbie` | `newbie12345` | права не подтверждены — на нём удобно показать проверку «Рули ID» |

### Полезные команды

```bash
docker compose logs -f backend                          # логи бэкенда
docker compose exec backend python manage.py test       # тесты (на MySQL)
docker compose exec backend python manage.py seed_demo --force   # сбросить автопарк к демо-состоянию

```

## Чем «Рули» отличается от Hello, Anytime и Делимобиля

1. **Честная бронь по маршруту.** Бесплатное ожидание не фиксированные 10 минут, а считается
   по реальному пешему маршруту до машины (OSRM): `время пешком × 1,3 + 3 мин`, от 10 до 25 минут,
   у «Допуска Плюс» +5. Если машины нет на месте (клиент в 300 м от точки), бронь снимается
   бесплатно и предлагается ближайшая замена.
2. **Паспорт кузова.** Перед поездкой и после неё — акт осмотра: 4 фото, отметки на силуэте,
   чистота салона. Каждый акт запечатан хэшем SHA-256, в который входит хэш предыдущего акта
   машины, — подмену задним числом видно по разрыву цепочки. Повреждения, которые уже были
   в паспорте, клиенту не приписываются; спорное новое повреждение можно оспорить 24 часа.
3. **Рули ID — проверка водителя как у настоящих KYC-сервисов.** Пять шагов, и на каждом
   выдуманные данные отсекаются до модератора:
   - **телефон** — одноразовый код из SMS (хранится только хэш, 5 попыток, повтор через минуту);
   - **личный номер** паспорта РБ — контрольная цифра по ICAO 9303 и зашитая в номер дата рождения
     должны сойтись с анкетой;
   - **реестр ВУ ГАИ** (имитация в админке) — номер прав существует, принадлежит этому человеку,
     даты совпадают, водитель не лишён прав. Лишили после одобрения — поездки закрываются сразу;
   - **документы — только живой камерой** в приложении, без загрузки из галереи;
   - **проверка «живости»** — сервер выбирает 3 случайных движения (повернуть голову, улыбнуться…),
     на съёмку 2 минуты; если кадры почти одинаковые (фото или экран перед камерой), проверка не пройдена.

   Модератор видит баллы риска, сверку с реестром, кадры «живости» рядом с паспортом. После одобрения
   ФИО в профиле не меняется, а новый номер телефона снова требует SMS-код. Доступ растёт ступенями:
   Гость → На проверке → Проверенный водитель → Допуск Плюс.
4. **«Кто за рулём?»** Перед каждой поездкой — 5 секунд перед фронтальной камерой: машина открывается
   только владельцу аккаунта, аккаунт нельзя «одолжить» другу без прав.
5. **«Куда едем?»** Клиент вводит адрес — приложение сравнивает ближайшие машины по полной цене
   поездки (пешком + бронь + дорога по лучшему тарифу) и показывает, сколько сэкономит выгодная машина
   по сравнению с ближайшей. Маршрут на машине — OSRM с запасом 25 % на пробки.
6. **«Движ» — баллы, задания и рейтинг.** +10 баллов за поездку и +1 за каждые 2 минуты, задания недели
   («3 поездки», «60 минут за рулём», «Ночная поездка», «Прокатись на Signature»), 11 достижений-«тегов»,
   ранги на сленге райтеров (Той → Райтер → Бомбер → Кинг → Легенда), рейтинг райдеров за 7/30 дней
   и всё время, «Приведи друга» (по 150 баллов обоим после первой поездки друга). Баллами можно
   оплатить до 30% поездки: 100 баллов = 1 BYN, скидка видна в чеке отдельной строкой.
7. **Signature.** Часть машин в граффити-оклейке с «тегом» «Р» на крыше.
   Если такая машина грязная — с фото салона первые 15 минут поездки бесплатно.

## Дизайн «Рули Street» и приложение на телефон

- Граффити-стиль: кобальтовая «стена», кислотно-жёлтая краска с потёками (Rubik Wet Paint),
  розовый второй слой, стикеры с жёсткой тенью. Две темы — «Ночь» и «День», по умолчанию как в системе.
- **PWA**: манифест, иконки, service worker (оболочка и карта работают из кэша, `/api/` — только сеть),
  экран «Нет сети», уведомление о новой версии.
- **Установка**: при первом запуске — обучалка, последний слайд предлагает поставить Рули на главный
  экран; кнопка есть и в меню «Ещё». На Android/Chrome — системное окно в одно нажатие, на iPhone —
  пошаговая инструкция «Поделиться → На экран „Домой“». Если приложение уже установлено, установку
  не предлагаем.
- Установка и камера работают только по HTTPS (или на `localhost`). Чтобы открыть стенд на телефоне,
  нужен HTTPS-туннель, например:

  ```bash
  cloudflared tunnel --url http://localhost
  ```

  В демо-режиме бэкенд принимает адреса `*.trycloudflare.com`.

## Обучение по приложению

- **Знакомство** при первом запуске — 5 слайдов о фишках Рули и предложение установить приложение.
- **Тур по экрану** сразу после знакомства: подсветка «Куда едем?», списка машин, фильтров, кнопки
  «Где я», вкладок «Движ» и «Рули ID», меню. Повторить можно на странице «Обучение и помощь».
- **Помощь** (`/help`) — частые вопросы: бронь, ожидание, осмотр, селфи перед поездкой, баллы, цены.

## Демо-режим и боевой режим

`KYC_DEMO_MODE=True` (по умолчанию в docker-compose) — учебный стенд: код SMS показывается на экране,
есть кнопки «Заполнить демо-данными», «Демо-документы», «Демо-кадры». Такие документы помечаются,
модератор видит их с пометкой «ДЕМО» и +30 баллов риска. При `KYC_DEMO_MODE=False` и `SMS_DEMO_MODE=False`
демо-кнопки исчезают, а сервер отклоняет демо-изображения.

## Карта: почему не 2GIS и не Mapbox

Оба сервиса требуют ключ, зарегистрированный на владельца: у Mapbox нужна привязка банковской карты
и проприетарная лицензия (с v2), у 2GIS демо-ключ действует месяц, дальше — платно.
Для курсовой выбран **MapLibre GL** (открытый форк Mapbox GL с тем же API) и векторные тайлы
**OpenFreeMap** без ключей; стиль перекрашен под палитру приложения, подписи на русском.
Адрес стиля задаётся переменной `VITE_MAP_STYLE_URL` — подключить другой провайдер можно
без правок кода. Пешие маршруты строит OSRM (FOSSGIS) через бэкенд: запросы кэшируются,
координаты округляются до ~11 м, при недоступности сервиса работает оценка по прямой.

На общем плане машины — точки (свободные графитовые, у Signature — шампань-сердцевина),
при приближении превращаются в силуэты вида сверху в цвете кузова; на дальнем плане
точки собираются в кластеры.

## Архитектура

```
Браузер ──► nginx (:80, единственный опубликованный порт)
              ├── /            → собранное React-приложение
              ├── /api/, /admin/ → gunicorn + Django (backend, :8000)
              └── /static/, /media/ → общие тома со статикой и фото осмотров
                                     │           (документы водителей — в закрытом томе,
                                     ▼            по URL не отдаются)
                                 MySQL 8.4 (db)
```

У `backend` и `db` нет опубликованных портов, поэтому все внешние запросы проходят через Nginx.

При старте контейнер бэкенда сам дожидается MySQL, применяет миграции, собирает
статику и заполняет пустую базу демо-данными. Повторный запуск данные не сбрасывает.

| Слой | Технологии |
|---|---|
| Бэкенд | Python 3.12, Django 5.2, Django REST Framework, JWT (simplejwt), gunicorn |
| База данных | MySQL 8.4, кодировка utf8mb4 |
| Фронтенд | React 18, Vite, React Router, TanStack Query, Axios |
| Карта | MapLibre GL + OpenFreeMap, маршруты OSRM |
| Инфраструктура | Docker Compose, nginx |

## Модель данных

- **User** — клиент или администратор, ФИО, телефон; данные прав заполняются только из одобренной заявки
- **ClassRequirement** — требования класса: возраст, стаж, число чистых поездок
- **DriverVerification / VerificationDocument / VerificationEvent** — заявка «Рули ID» (с личным номером и баллами риска), фото документов (закрытое хранилище), журнал действий модератора
- **PhoneCode** — хэш одноразового кода из SMS, срок и число попыток
- **LicenseRegistryRecord** — имитация реестра водительских удостоверений ГАИ
- **LivenessCheck / LivenessFrame** — проверки «живости» (для Рули ID и перед поездкой) и их кадры
- **PointsEntry** — журнал баллов «Движа» (баланс = сумма строк, ключ не даёт начислить дважды)
- **Referral** — кто кого пригласил и когда начислена награда
- **Tariff** — цена минуты, ожидания, пакеты «Час» и «Сутки»
- **Feature** — опция автомобиля
- **Car** — марка, модель, госномер, класс, координаты, статус, ливрея (`none` / `graphite` / `ivory`), дата мойки
- **Rental** — аренда: статус, цены на момент брони, бесплатное ожидание по маршруту, причина отмены, компенсация
- **Inspection / InspectionPhoto / Damage** — акты осмотра с хэш-цепочкой, фото ракурсов, повреждения и кто за них отвечает

## Бизнес-логика аренды

Статусы: `reserved → active → completed` или `reserved → cancelled`. Каждый переход
выполняется в транзакции; машина блокируется `SELECT … FOR UPDATE`.

- **Цены фиксируются в момент брони.**
- **Ожидание** бесплатно на время «честной брони», дальше — по цене ожидания тарифа.
- **Начать поездку** можно только после акта осмотра, **завершить** — после финального акта.
- **Поездка**: каждая начатая минута; система сама выбирает поминутно, «Час» или «Сутки».
- **Итог** = стоимость поездки (минус минуты гарантии Signature) + платное ожидание.

## Сценарий для защиты

1. Войти как `demo` → список «Ближе всего»: слева время пешком, сверху ближайшая машина.
2. Забронировать → на карте пеший маршрут и время, кольцо бесплатного ожидания.
3. «Демо: дойти до машины» → метка проходит по маршруту, появляется «Машины нет на месте».
4. «Осмотреть машину» → «Демо-фото для защиты» → акт запечатан → «Начать поездку».
5. Финальный осмотр → «Завершить поездку» → чек с печатями обоих актов.
6. На карте «Куда едем?» → «Минск-Арена» → список машин по полной цене поездки, плашка «сэкономите N BYN».
7. Зарегистрировать новый аккаунт → «Рули ID»: код из SMS (показан на экране) → «Заполнить демо-данными»
   → согласия → «Демо-документы» → проверка «живости» (камера ноутбука или «Демо-кадры») → отправка.
8. Показать отказ: в анкете номер `6KX 000777` (лишён прав) или выдуманный номер — автопроверка не пустит.
9. В админке (`admin`) → «Заявки Рули ID» → риск, сверка с реестром, кадры лица → «Одобрить».
10. «Реестр ВУ» в админке → поставить водителю «Лишение права управления» → бронь сразу закрыта.
11. Вкладка «Движ» → баланс и ранг, задания недели, достижения, пьедестал рейтинга, код «Приведи друга».
    Завершить поездку с галочкой «Оплатить баллами» → в чеке скидка и полученные баллы.
12. Меню «Ещё» → «Обучение и помощь» → «Тур по экрану».

## Безопасность и персональные данные

- Все порты опубликованы только на `127.0.0.1`: с других компьютеров сети приложение недоступно
  (демо-пароли известны всем, кто видел защиту).
- Сканы документов лежат в отдельном томе и по URL не отдаются; модератор открывает их через
  админку, каждый просмотр пишется в журнал, который нельзя удалить. Метаданные фото стираются.
- Фото принимаются только JPEG/PNG/WebP до 25 Мп — защита от «бомб распаковки».
- Через 30 дней после решения (или если черновик заброшен) файлы удаляются командой
  `purge_verification_files`, она запускается при каждом старте контейнера. Файлы удаляются
  только после фиксации транзакции.
- Вход ограничен 10 попытками в минуту, регистрация — 5 в час, загрузка документов — 60 в час,
  SMS-коды — 8 в час, проверки «живости» — 30 в час.
- Кадры лица — биометрия: удаляются при отзыве согласия, кадры перед поездками — через 30 дней.
- Координаты машины после поездки не берутся от клиента — их нельзя подделать.

## Разработка фронтенда без пересборки образа

Проверка вёрстки на телефоне: `npm run dev` и страница http://localhost:5173/devices.html?p=/,/rewards,/verification —
несколько экранов шириной 375 px рядом (файл только для разработки, в сборку не попадает).


```bash
cd frontend
npm install
npm run dev
```

Приложение откроется на http://localhost:5173, запросы к `/api` и `/admin`
проксируются через опубликованный Nginx на `http://localhost` (порт 80 по умолчанию).
Если для Nginx задан другой `HTTP_PORT`, укажи тот же адрес переменной `VITE_DEV_PROXY_TARGET`,
например `http://localhost:8088`.

## Изображения автомобилей

- **Фото в карточках** — реальные фотографии с Викисклада (CC0, CC BY, CC BY-SA), у которых
  нейросетью rembg удалён фон. Авторы и лицензии — в [frontend/public/cars/SOURCES.md](frontend/public/cars/SOURCES.md).
- **Машины на карте** — векторный рисунок вида сверху (`frontend/src/utils/carVisual.js`) в цвете
  кузова, без полос; у машин Signature — фирменная крыша и граффити-тег «Р».
